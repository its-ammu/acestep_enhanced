Step 1: Stem Separation

Mel-Band RoFormer + Demucs v4

GPU ~4GB Freed after

Mel-Band RoFormer (SDR ~11.2) produces the highest quality vocal isolation. Output: vocals.wav (preserved for final mix) + instrumental.wav (structural source for cover).

Demucs v4 (htdemucs_ft) produces drums.mp3, bass.mp3, other.mp3 for per-section energy analysis and melodic instrument detection.

Step 2: Metadata Detection

BPM + Key + Time Signature

Why bass disambiguation matters: Standard detection confuses Eb Major / C Minor (same pitch classes). Wrong key causes the DiT to generate out-of-key notes (e.g., C# in a C Minor song).

3.2 Qwen Analysis (Loaded Once, ~5 Inference Passes)

Per-Stem Descriptions (3 calls)

Each Demucs stem fed individually to Qwen with targeted prompts:

  • Drums: "Describe the drum patterns... kick pattern, snare pattern, cymbal pattern, groove feel."
  • Bass: "Describe the bass... instrument type, tone, playing technique, note patterns."
  • Other: "Describe the melodic instruments... what instruments, timbre, effects, playing style."

Caption Generation (1 call)

Qwen listens to the full mix with stem descriptions as context. Produces a 50-80 word production caption describing each instrument's tone and playing style. Truncated to 2 sentences.

Per-Section Hints (N calls + DSP)

For each section, a hybrid approach:

ComponentMethodDetects
Drums/bass presenceRMS energy > -40dBIs this instrument audible?
Solo vote 1Spectral flux > 0.03High melodic movement
Solo vote 2Energy ratio > 1.5x averageSection louder than normal
Solo vote 3Qwen chunk analysis"solo"/"lead"/"melody" in response
Instrument + styleQwen (2-3 words)"Guitar Power Chords", "Synth Arpeggios"
Ensemble rule: ALL 3 votes must agree for "solo" override. Otherwise, Qwen's 2-3 word description is used directly.

Genre Selection (1 call)

Qwen picks ONE number from 10 pre-defined genre options. This is a classification task — far more reliable than free-form instrument naming.

Genre options:
1. Synthwave    → Electronic Drum Machine, Analog Bass, Analog Synth Lead
2. Funk         → Tight Funk Drums, Slap Bass, Rhodes Piano
3. Industrial   → Aggressive Rock Drums, Distorted Synth Bass, Distorted Synth
4. Neo-Soul     → Live Rock Drums, Electric Bass, Rhodes Piano
5. Disco        → Disco Drums, Electric Bass, Analog Synth Pad
6. Trip-Hop     → Breakbeat Drums, Sub Bass, Analog Synth Pad
7. Latin Rock   → Bongo Congas, Fingerpicked Bass, Nylon Guitar
8. Electro-Funk → 808 Drum Machine, Moog Bass, Analog Synth Lead
9. Post-Punk    → Aggressive Rock Drums, Electric Bass, Analog Synth Lead
10. Cinematic   → Orchestral Percussion, Cello, Trumpet

3.3 Template Caption (build_caption_from_instruments)

From the genre instruments, a rich performance description is generated via template matching. Includes HOW to play, not just WHAT instrument:

// Example for Trip-Hop (genre 6):
// instruments = {drums: "Breakbeat Drums", bass: "Sub Bass", melodic: "Analog Synth Pad"}

"lush analog synth pad with slow evolving textures, wide stereo chorusing,
subtle filter movement, harmonic swells building through choruses.
Breakbeat Drums with tight groove and dynamic fills,
deep sub bass locking with kick drum pattern.
Professional production, punchy mix, wide stereo field."

3.4 Translate Temporal Script

Original hints (with instrument names) are translated to energy-only tags. The caption already declares instruments — lyrics just say when to change energy:

[Instrumental]

[Verse 1 - moderate energy]
[Instrumental]

[Chorus 1 - high energy, powerful]
[Instrumental]

[Verse 2 - moderate energy]
[Instrumental]

[Chorus 2 - high energy, driving]
[Instrumental]

[Bridge - building energy]
[Instrumental]

[Chorus 3 - peak energy, anthemic]
[Instrumental]

[Outro - fade out]
[Instrumental]
Escalating intensity: Later choruses automatically get stronger energy tags ("powerful" → "driving" → "peak energy, anthemic"). This creates a natural build through the song.

Denoising starts from 40% source latent + 60% noise. CFG pushes toward caption. Timbre encoder grounds the target sound.

How Reference Audio Is Consumed

Inside the DiT, the reference audio flows through:

  1. VAE Encode: Reference audio → VAE encoder → latent [1, T, 64]
  2. Timbre Encoder: A transformer that processes the reference latents:
    • Projects 64-dim → hidden_size
    • Prepends CLS token for aggregation
    • Self-attention extracts global timbre signature
  3. Conditioning Assembly: Packed sequence = lyrics + timbre + text caption
  4. Cross-Attention: During denoising, the DiT cross-attends to the combined conditioning
Both passes use identical: caption, lyrics, BPM, key, guidance_scale, inference_steps, shift. The only differences are task_type (text2music vs cover), target_wavs (silence vs instrumental), and refer_audios (None vs Pass 1 output).

Why No Hints in V48

Hints + CFG conflict: 25Hz bass hints guide latent-level chord voicings (pull toward original harmony). High guidance_scale pushes toward genre caption (pull toward new instruments). These fight at the latent level — the model can't satisfy both. Result: chroma dropped from 0.30 to 0.35 (worse than either alone).

V48's trade-off: Accept lower chord accuracy (0.30-0.49) in exchange for strong genre shift. Let audio_cover_strength=0.4 handle whatever structural preservation it can.

Step 5: Post-Generation QC

Per-Bar Analysis + Repaint

Reuses loaded handler

Detection

CheckMethodThreshold
Bass dropoutLow-frequency RMS energy< -45dB where original has bass
Out-of-key notesChroma vs key scaleNon-scale pitch class energy > 2x in-scale
Wrong chord rootChroma argmax comparisonRoot doesn't match original bar

Repair

For each failing section:

  • Uses native repaint task — only regenerates the failing time range
  • audio_cover_strength=0.6 (higher than initial 0.4) — locks chords more tightly on retry
  • Different random seed each attempt
  • Up to 3 attempts per section
  • If all fail: keeps original section unchanged (never degrades)

Key Design Decisions

DecisionRationale
No bass hintsHints + CFG fight at latent level, degrading both chord accuracy and genre shift
No LM caption refinementLM ignores genre intent, rewrites captions to random genres
Template captions (not Qwen)Qwen captions were inconsistent/rambling; templates guarantee genre-specific performance descriptions
Genre number selection (not free-form)Classification task is far more reliable than asking Qwen to name instruments
Full-duration timbre referenceCaptures dynamic energy arc (quiet verses, loud choruses) — not just a static timbre sample
audio_cover_strength=0.4Sweet spot: preserves gross timing/structure, allows radical instrument/harmony rewrite
QC repaint at acs=0.6Higher than initial (0.4) to lock chords tighter on retry, while maintaining some genre character
